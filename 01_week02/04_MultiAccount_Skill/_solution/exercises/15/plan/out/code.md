`final_price(amount)` ทำงานตามนี้:
- **ตั้งแต่ 1,000 ขึ้นไป:** คืน `amount * 0.90` (ลด 10%)
- **ตั้งแต่ 500 ถึงต่ำกว่า 1,000:** คืน `amount * 0.95` (ลด 5%)
- **ต่ำกว่า 500:** คืน `amount` เท่าเดิม ยอด 0 จึงคืน 0
- **ยอดติดลบ:** raise `ValueError`
