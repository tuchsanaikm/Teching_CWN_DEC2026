# แบบฝึกหัดที่ 8 · ส่งต่อ 3 ทอด

ผลจากการรันจริง 1 ครั้ง ผลของแต่ละคนจะต่างกันไปตามบัญชี รุ่น และวันที่รัน

## พรอมต์

```text
ใช้สกิล agent-team ใน container multi-account ส่งงานต่อกัน 3 ทอด ด้วย yolo1, cyolo1 และ gyolo1 งานทุกชิ้นใช้ความยาก 1
1. yolo1 เขียนคำขวัญของร้านหนังสือเล็ก ๆ 1 ประโยคเป็นภาษาไทย
2. cyolo1 แปลคำขวัญนั้นเป็นภาษาอังกฤษ
3. gyolo1 นับจำนวนคำของประโยคภาษาอังกฤษ ตอบเป็นตัวเลขตัวเดียว
สรุปเป็นตาราง: งาน | บัญชี | ผลที่ได้ | รับข้อมูลจากใคร | เวลา (วินาที) แล้วเก็บแผนงานที่ใช้ไว้ที่ ./exercises/08
```

## คำตอบของ Claude

ทั้ง 3 ทอดทำงานสำเร็จใน run `20261124-051920-ftnt` ทุกงานใช้ความยาก 1 และไม่มีการย้ายบัญชีระหว่างทาง

| งาน | บัญชี | ผลที่ได้ | รับข้อมูลจากใคร | เวลา (วินาที) |
|---|---|---|---|---|
| 1. เขียนคำขวัญ (slogan) | yolo1 (haiku/low) | ร้านหนังสือเล็ก ๆ ของเรา มีเรื่องราวรอให้คุณค้นพบ | (งานแรก ไม่มี) | 2.8 |
| 2. แปลเป็นภาษาอังกฤษ (translate) | cyolo1 (gpt-6.2-sol/low) | Our little bookshop is full of stories waiting for you to discover. | yolo1 | 7.5 |
| 3. นับคำ (count) | gyolo1 (gemini-3.8-flash-low) | 12 | cyolo1 | 5.6 |

รวมเวลาประมาณ 15.9 วินาที ผมนับคำในประโยคภาษาอังกฤษเองแล้ว ได้ 12 คำตรงกับที่ gyolo1 ตอบ

ไฟล์ที่เก็บไว้ใน `./exercises/08`:
- `graph.json` คือแผนงาน ใช้รันซ้ำได้
- `result.json` คือผลของ run นี้ ต้นไฟล์มีบรรทัดแสดงความคืบหน้าปนอยู่ก่อนส่วนที่เป็น JSON

ผลของแต่ละงานยังอยู่ใน container ที่ `/workspace/.agent-team/20261124-051920-ftnt/`

ถ้าจะรันแผนนี้อีกครั้ง ให้ใช้คำสั่งนี้ใน Git Bash จากโฟลเดอร์ `exercises/08`:
```
cat graph.json | docker exec -i multi-account python3 //root/ai-accounts/.Claude/shared/skills/agent-team/scripts/team.py run - --workers yolo1,cyolo1,gyolo1
```
