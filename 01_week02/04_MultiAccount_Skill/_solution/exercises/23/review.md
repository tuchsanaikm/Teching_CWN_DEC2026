# ผลตรวจ `slug.py`

## ปัญหาที่ต้องแก้

- **`slugify()` คืนสตริงว่างที่ใช้เป็นชื่อไฟล์ไม่ได้** เมื่ออินพุตว่างหรือถูกตัดออกทั้งหมด เช่น `''`, `'!@#$%^&*()_+'`, `' \t\n '` และ `'---'` ทุกกรณีคืน `''` จาก `slug.py` บรรทัด 9–11 ควรกำหนดให้ชัดว่าจะปฏิเสธอินพุตด้วย `ValueError` หรือคืนชื่อสำรองที่ไม่ว่าง

## ผลทดสอบ

| กรณี | อินพุต | ผลจริง |
| --- | --- | --- |
| เว้นวรรคซ้อน | `'Hello   World'` | `'hello-world'` |
| ขีดกลางซ้อน | `'Hello---World'` | `'hello-world'` |
| ขีดกลางหัวท้าย | `'--Hello World---'` | `'hello-world'` |
| สตริงว่าง | `''` | `''` |
| อักขระพิเศษล้วน | `'!@#$%^&*()_+'` | `''` |
| ตัวเลข | `'2026'` | `'2026'` |
| อักษรมีเครื่องหมาย | `'Café Déjà Vu'` | `'cafe-deja-vu'` |
| ขีดล่าง | `'foo_bar'` | `'foobar'` |
| แท็บและขึ้นบรรทัด | `'Hello\tWorld\nAgain'` | `'hello-world-again'` |
| ช่องว่างล้วน | `' \t\n '` | `''` |
| ขีดกลางล้วน | `'---'` | `''` |
