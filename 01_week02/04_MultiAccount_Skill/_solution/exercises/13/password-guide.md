# คู่มือการตั้งรหัสผ่านให้ปลอดภัย

รหัสผ่านคือด่านแรกที่ปกป้องอีเมล บัญชีธนาคาร โซเชียลมีเดีย และข้อมูลส่วนตัวของคุณ การตั้งรหัสผ่านที่ดีไม่ต้องซับซ้อนจนจำไม่ได้ แต่ต้องยาว คาดเดายาก และไม่ซ้ำกัน คู่มือนี้สรุปแนวทางที่นำไปใช้ได้ทันที

## 1. หลักการสำคัญ

- **ยาวดีกว่าซับซ้อน** ใช้อย่างน้อย 12–16 ตัวอักษรขึ้นไป ยิ่งยาวยิ่งถูกเดาหรือเจาะได้ยาก
- **วลีผ่าน (passphrase)** ใช้คำสุ่มหลายคำต่อกัน เช่น 4–5 คำ จำง่ายแต่เดายาก
- **หนึ่งบัญชี หนึ่งรหัสผ่าน** ห้ามใช้ซ้ำ เพราะหากเว็บใดเว็บหนึ่งรั่ว ผู้ไม่หวังดีจะนำรหัสนั้นไปลองกับบัญชีอื่นของคุณ
- **ไม่ใช้ข้อมูลส่วนตัว** เช่น ชื่อ วันเกิด เบอร์โทร ชื่อสัตว์เลี้ยง ชื่อทีมฟุตบอล ซึ่งหาได้จากโซเชียลมีเดีย
- **ไม่แชร์และไม่จดทิ้งไว้** อย่าส่งรหัสผ่านทางแชตหรืออีเมล และไม่แปะโน้ตไว้ข้างจอ
- **เปลี่ยนเมื่อจำเป็น** เปลี่ยนทันทีเมื่อสงสัยว่ารั่ว หรือได้รับแจ้งว่าบริการถูกเจาะ ไม่จำเป็นต้องเปลี่ยนทุกเดือนโดยไม่มีเหตุ

## 2. ตัวอย่างที่ดีและไม่ดี

| ไม่ดี ❌ | เหตุผล |
|---|---|
| `123456`, `password`, `qwerty` | อยู่ในรายการที่ถูกลองเป็นอันดับแรกเสมอ |
| `somchai2540` | มีชื่อและปีเกิด เดาง่าย |
| `P@ssw0rd!` | สลับตัวอักษรตามแบบที่ใคร ๆ ก็ทำ แฮ็กเกอร์รู้ทัน |
| `Abc12345` ใช้กับทุกเว็บ | ใช้ซ้ำ รั่วที่เดียวเสียทั้งหมด |

| ดี ✅ | เหตุผล |
|---|---|
| `ช้างม้าเรือบินกาแฟเย็น` หรือ `lamp-River-9-cloud-tiger` | ยาว สุ่ม นึกเป็นภาพแล้วจำง่าย |
| `x7#Kq9!vLm2$Rt8Z` (สร้างโดยโปรแกรม) | สุ่มจริง เหมาะกับบัญชีที่ไม่ต้องจำ |

*หมายเหตุ: ตัวอย่างข้างต้นใช้เพื่อการอธิบายเท่านั้น ห้ามนำไปใช้จริง*

## 3. การใช้ Password Manager

คนทั่วไปไม่สามารถจำรหัสผ่านยาวและไม่ซ้ำกันได้หลายสิบบัญชี จึงควรใช้โปรแกรมจัดการรหัสผ่าน เช่น Bitwarden, 1Password หรือตัวจัดการที่มีในเบราว์เซอร์และระบบปฏิบัติการ

1. เลือกบริการที่น่าเชื่อถือและมีการเข้ารหัสข้อมูลฝั่งผู้ใช้
2. ตั้ง **master password** เป็นวลีผ่านที่ยาวและแข็งแรงที่สุด จำให้ได้เพียงรหัสเดียว และห้ามใช้ที่อื่น
3. ให้โปรแกรมสร้างรหัสผ่านสุ่มสำหรับทุกบัญชีใหม่ แล้วทยอยเปลี่ยนบัญชีเก่า เริ่มจากอีเมลและบัญชีการเงิน
4. เปิด MFA ให้กับตัว password manager เองด้วย
5. สำรองรหัสกู้คืน (recovery code) เก็บไว้ในที่ปลอดภัยแบบออฟไลน์

## 4. การยืนยันตัวตนหลายขั้นตอน (MFA)

MFA คือการเพิ่มด่านที่สองนอกจากรหัสผ่าน ทำให้ต่อให้รหัสรั่ว ผู้ไม่หวังดีก็ยังเข้าบัญชีไม่ได้ ควรเปิดใช้ทุกบริการที่รองรับ โดยเฉพาะอีเมล ธนาคาร และคลาวด์

ลำดับความปลอดภัย (จากสูงไปต่ำ):

- **กุญแจความปลอดภัย (security key) และ Passkey** ปลอดภัยที่สุด ป้องกันเว็บปลอมได้
- **แอปสร้างรหัส (Authenticator)** เช่น Google Authenticator, Microsoft Authenticator
- **SMS** สะดวกแต่เสี่ยงต่อการถูกดักหรือโอนซิม ใช้เมื่อไม่มีทางเลือกอื่น

ข้อควรระวัง: อย่าบอกรหัส OTP แก่ใครเด็ดขาด แม้จะอ้างว่าเป็นเจ้าหน้าที่ธนาคารหรือผู้ให้บริการ และตรวจสอบที่อยู่เว็บไซต์ทุกครั้งก่อนกรอกข้อมูล

## สรุปเช็กลิสต์

- [ ] รหัสผ่านยาว 12 ตัวอักษรขึ้นไป และไม่ซ้ำกัน
- [ ] ใช้ password manager และมี master password ที่แข็งแรง
- [ ] เปิด MFA ที่อีเมลและบัญชีสำคัญทั้งหมด
- [ ] ไม่แชร์รหัสผ่านและรหัส OTP กับใคร
