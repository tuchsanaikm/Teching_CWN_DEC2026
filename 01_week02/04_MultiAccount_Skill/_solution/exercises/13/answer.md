# แบบฝึกหัดที่ 13 · ให้สกิลเลือกคนเอง

ผลจากการรันจริง 1 ครั้ง ผลของแต่ละคนจะต่างกันไปตามบัญชี รุ่น และวันที่รัน

## พรอมต์

```text
ใช้สกิล agent-team ใน container multi-account ให้สกิลเลือกบัญชีเองตามชนิดของงาน โดยไม่ระบุบัญชีในงานใดเลย งานทุกชิ้นใช้ความยาก 2
1. งานเขียนโค้ด: ฟังก์ชัน Python ตรวจว่าปีใดเป็นปีอธิกสุรทิน
2. งานตรวจโค้ด: ตรวจฟังก์ชันจากงานที่ 1 แล้วเขียนจุดที่ควรแก้
3. งานเอกสารยาว: คู่มือการตั้งรหัสผ่านให้ปลอดภัย ยาวประมาณ 1 หน้า
4. งานทั่วไป: ตั้งชื่อทีมฟุตบอลของบริษัท 5 ชื่อ
สรุปเป็นตาราง: งาน | ชนิดของงาน | บัญชีที่สกิลเลือก | เหตุผลที่สกิลเลือกค่ายนั้น แล้วเก็บแผนงานที่ใช้ไว้ที่ ./exercises/13
```

## คำตอบของ Claude

ผมรันงานทั้ง 4 ชิ้นด้วยสกิล agent-team ใน container `multi-account` แล้ว สำเร็จครบทุกงาน (run `20261124-053820-pecp`) ไม่ได้ระบุบัญชีในงานใดเลย ทุกงานใช้ความยาก 2 สิ่งที่บอกชนิดงานให้สกิลมีแค่ช่อง `kind` ส่วนการเลือกบัญชีเป็นหน้าที่ของ router ในสกิลเอง

| งาน | ชนิดของงาน | บัญชีที่สกิลเลือก | เหตุผลที่สกิลเลือกค่ายนั้น |
|---|---|---|---|
| 1. ฟังก์ชันตรวจปีอธิกสุรทิน | `code` | cyolo1 (Codex, gpt-6.2-sol/medium) | สกิลส่งงาน `code` ไป Codex ก่อน และ cyolo1 ได้คะแนนต่ำสุดในค่าย (ใช้โควตาไป 10% ไม่มีงานค้าง) |
| 2. ตรวจโค้ดจากงานที่ 1 | `review` | cyolo2 (Codex, gpt-6.2-sol/medium) | สกิลส่งงาน `review` ไป Codex ก่อน แต่ cyolo1 มีงาน code อยู่แล้วจึงถูกบวกคะแนนเพิ่ม 15 งานนี้เลยไปที่ cyolo2 |
| 3. คู่มือรหัสผ่าน ~1 หน้า | `doc` | yolo2 (Claude, sonnet/medium) | สกิลส่งงาน `doc`/`long` ไป Claude ก่อน และ yolo2 ใช้โควตาน้อยสุด (1% ส่วน yolo1 ใช้ 30% และ yolo3 ใช้ 47%) |
| 4. ชื่อทีมฟุตบอล 5 ชื่อ | ทั่วไป (ไม่มี kind) | gyolo1 (Antigravity, gemini-3.8-flash-medium) | งานที่ไม่มี kind จะได้บัญชีที่คะแนนต่ำสุดจากทั้ง 3 ค่าย ซึ่งคือ gyolo1 (session 5%, week 1%, ยังไม่มีงานในคิว) |

สกิลข้ามบัญชีที่ยังไม่ได้ล็อกอินให้เอง ได้แก่ yolo4–5, cyolo3–5 และ gyolo3–5

**ผลของแต่ละงาน:**
- **งานที่ 1:** ได้ฟังก์ชัน `is_leap_year` บรรทัดเดียว คำนวณถูกตามกฎปฏิทินเกรกอเรียน
- **งานที่ 2:** ผู้ตรวจเทียบกับ `calendar.isleap` ตั้งแต่ปี 1 ถึง 9999 แล้วตรงกันทุกปี จุดที่แนะนำให้แก้มี 4 ข้อ:
  - ยังไม่ตรวจชนิดข้อมูล ตอนนี้ `False` และ `2024.0` ผ่านได้ทั้งคู่
  - ยังไม่กำหนดว่ารับปี 0 และปีติดลบหรือไม่
  - ยังไม่มี docstring
  - ยังไม่มีชุดทดสอบ
- **ข้อสังเกตงานที่ 2:** ผู้ตรวจเป็นคนละบัญชีกับผู้เขียนโค้ด แต่อยู่ค่าย Codex เดียวกัน การตรวจจึงยังไม่ใช่การตรวจข้ามค่าย
- **งานที่ 3:** Claude ไม่ได้เขียนคู่มือไว้ในคำตอบ แต่บันทึกเป็นไฟล์แยกใน run folder ผมคัดลอกไฟล์นั้นออกมาให้แล้ว คู่มือมี 4 หัวข้อและเช็กลิสต์ท้ายเรื่อง ผมยังไม่ได้นับคำว่าได้ประมาณ 1 หน้าตามที่ขอหรือไม่
