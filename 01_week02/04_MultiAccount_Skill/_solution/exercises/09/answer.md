# แบบฝึกหัดที่ 9 · ทำพร้อมกันแล้วรวมผล

ผลจากการรันจริง 1 ครั้ง ผลของแต่ละคนจะต่างกันไปตามบัญชี รุ่น และวันที่รัน

## พรอมต์

```text
ใช้สกิล agent-team ใน container multi-account ให้ 3 ค่ายทำงานพร้อมกันแล้วรวมผล ด้วย yolo1, cyolo1 และ gyolo1 งานทุกชิ้นใช้ความยาก 1
1. ทำพร้อมกัน: แต่ละบัญชีเขียนข้อควรระวัง 2 ข้อของการใช้ AI เขียนโค้ด
2. yolo1 รวมทั้ง 6 ข้อเป็นรายการเดียว และตัดข้อที่ซ้ำกันออก
สรุปเป็นตาราง: งาน | บัญชี | เวลา (วินาที) แล้วเทียบเวลาที่ใช้จริงทั้งหมดกับผลรวมเวลาของทุกงาน ว่าการทำพร้อมกันประหยัดเวลาไปเท่าไร เก็บแผนงานที่ใช้ไว้ที่ ./exercises/09
```

## คำตอบของ Claude

ทั้ง 4 งานเสร็จครบ (สถานะ `ok` ทุกงาน) ทุกงานใช้ความยาก 1 และไม่มีการย้ายบัญชี (run `20261124-052228-asak`)

**ผลที่รวมแล้ว (yolo1 รวม 6 ข้อและตัดข้อซ้ำออก 2 ข้อ เหลือ 4 ข้อ)**
1. ตรวจและทดสอบโค้ดที่ AI สร้างทุกครั้งก่อนใช้ เพราะอาจมีบั๊กหรือช่องโหว่ด้านความปลอดภัยแฝงอยู่ (Claude/Codex/Gemini ทั้งสามค่ายเขียนข้อนี้ จึงรวมเหลือข้อเดียว)
2. AI อาจใช้ไลบรารีหรือ API ที่ไม่มีอยู่จริงหรือเป็นเวอร์ชันเก่า ควรเทียบกับเอกสารทางการก่อน (Claude)
3. อย่าส่งรหัสผ่าน คีย์ API หรือข้อมูลลูกค้าให้ AI (Codex)
4. ถ้าพึ่ง AI มากเกินไป นักพัฒนาอาจเข้าใจระบบน้อยลงและแก้ปัญหาเองได้น้อยลง (Gemini)

**ตารางเวลา**

| งาน | บัญชี | เวลา (วินาที) |
|---|---|---|
| 1. ข้อควรระวัง 2 ข้อ | yolo1 (haiku/low) | 4.57 |
| 1. ข้อควรระวัง 2 ข้อ | cyolo1 (gpt-6.2-sol/low) | 6.95 |
| 1. ข้อควรระวัง 2 ข้อ | gyolo1 (gemini-3.8-flash-low) | 7.95 |
| 2. รวมและตัดข้อซ้ำ | yolo1 (haiku/low) | 6.14 |
| **ผลรวมเวลาทุกงาน** | | **25.61** |

**เทียบเวลา**
- เวลาที่ใช้จริงตาม ledger คือ 05:22:33 ถึง 05:22:47 ประมาณ **14 วินาที** ซึ่งเท่ากับงานขนานที่ช้าที่สุด (gyolo1 7.95) บวกงานรวม 6.14
- ถ้าทำทีละงานจะใช้ 25.61 วินาที การทำพร้อมกันจึง**ประหยัดไปราว 11.5 วินาที (ประมาณ 45%)**
- ถ้านับรวมตอนเริ่ม run และตอนดึงโควตาหลังจบ จะใช้เวลาเพิ่มอีกหลายวินาที
