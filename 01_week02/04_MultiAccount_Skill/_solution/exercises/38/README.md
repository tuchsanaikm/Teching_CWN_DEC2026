# แบบฝึก 38 — ผลของการจำกัดจำนวนงานที่ทำพร้อมกัน (`--per-account`)

แผนงาน: `graph.json` มีงานคำคม 6 ชิ้นที่ไม่ขึ้นต่อกัน ทุกชิ้นกำหนด `account: yolo1` และ `difficulty: 1` (haiku/low)

```bash
T=//root/ai-accounts/.Claude/shared/skills/agent-team/scripts/team.py
# ครั้งที่ 1: ทำพร้อมกันได้ทีละ 1 งาน
cat graph.json | docker exec -i multi-account python3 $T run - --workers yolo1 --per-account 1 --json > run1.json
# ครั้งที่ 2: ทำพร้อมกันได้ทีละ 3 งาน
cat graph.json | docker exec -i multi-account python3 $T run - --workers yolo1 --per-account 3 --json > run2.json
```

## ผล (จาก ledger.jsonl ของแต่ละ run)

| ครั้ง | งานพร้อมกันสูงสุด | เวลาที่ใช้จริงทั้งหมด (วินาที) | ผลรวมเวลาของทุกงาน (วินาที) |
|---|---|---|---|
| 1 (`20261124-054437-rgeu`) | 1 | 23 | 20.65 |
| 2 (`20261124-054517-swia`) | 3 | 9 | 25.03 |

- เวลาที่ใช้จริง = งานแรกเริ่ม → งานสุดท้ายเสร็จ (ละเอียดระดับวินาที) ถ้านับรวมการเริ่ม run และตรวจความพร้อมด้วยจะเป็น 27 และ 14 วินาที
- ครั้งที่ 1 งานรันต่อกันทีละงาน เวลาจริงจึงใกล้ผลรวมเวลา (ส่วนที่เกินคือช่วงว่างราว 1 วินาทีระหว่างงาน)
- ครั้งที่ 2 รันเป็น 2 รอบ รอบละ 3 งาน เวลาจริงลดลงราว 2.5 เท่า แต่ผลรวมเวลาของงานเพิ่มขึ้นเล็กน้อย (แต่ละงานช้าลงเมื่อรันพร้อมกันบนบัญชีเดียว)
- หมายเหตุ: `duration_s` ใน `run1.json` นับเวลารอคิวด้วย ใช้ค่าจาก ledger แทน
