## ผลการทดสอบสูตรด้วย Node (เทียบคำนวณมือกับโค้ดใน `split.html`)

1. **กรณีปัดขึ้น (`total = 1000`, `n = 3`, `svc = 10`)**
   - คำนวณมือ: `1000 × (100 + 10) / (100 × 3) = 110000 / 300 = 366.666667` → ปัดขึ้น = `367 บาท`
   - ผลจากโค้ด (`perPerson`): `367 บาท` (ตรงกัน)

2. **กรณีค่าบริการ 0% และปัดขึ้น (`total = 850`, `n = 3`, `svc = 0`)**
   - คำนวณมือ: `850 × (100 + 0) / (100 × 3) = 85000 / 300 = 283.333333` → ปัดขึ้น = `284 บาท`
   - ผลจากโค้ด (`perPerson`): `284 บาท` (ตรงกัน)

3. **กรณีกัน floating-point (`total = 100`, `n = 1`, `svc = 10`)**
   - คำนวณมือ: `100 × (100 + 10) / (100 × 1) = 11000 / 100 = 110.000000` → ปัดขึ้น = `110 บาท`
   - ผลจากโค้ด (`perPerson`): `110 บาท` (ตรงกัน)
