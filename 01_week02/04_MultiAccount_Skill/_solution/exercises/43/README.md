เปิดไฟล์ split.html ด้วยเว็บเบราว์เซอร์ได้ทันที เป็นไฟล์เดียว ไม่ต้องติดตั้งหรือต่ออินเทอร์เน็ต
กรอก "ยอดรวม" เป็นบาท (ทศนิยมได้, ตั้งแต่ 0 ขึ้นไป) และ "จำนวนคน" เป็นจำนวนเต็มตั้งแต่ 1 คนขึ้นไป
กรอก "ค่าบริการ" เป็นเปอร์เซ็นต์ (ค่าเริ่มต้น 0, ทศนิยมได้, ไม่มีเพดานบน) ผลจะคำนวณทันทีขณะพิมพ์ หรือกดปุ่ม "คำนวณยอดต่อคน"
ยอดต่อคน = ยอดรวม × (100 + ค่าบริการ) ÷ (100 × จำนวนคน) ปัดขึ้นเป็นบาทเต็ม เช่น 1000 บาท 4 คน ค่าบริการ 10% ได้ 275 บาท
ถ้ากรอกค่าผิด เช่น ว่าง ติดลบ หรือจำนวนคนเป็น 0 หรือ 2.5 จะมีข้อความแจ้งใต้ช่องนั้นและไม่แสดงผลลัพธ์จนกว่าจะแก้ให้ถูก
