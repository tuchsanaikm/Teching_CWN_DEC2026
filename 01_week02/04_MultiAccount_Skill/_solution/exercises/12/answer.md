# แบบฝึกหัดที่ 12 · แผนงานที่มีทั้งลำดับและทำพร้อมกัน

ผลจากการรันจริง 1 ครั้ง ผลของแต่ละคนจะต่างกันไปตามบัญชี รุ่น และวันที่รัน

## พรอมต์

```text
ใช้สกิล agent-team ใน container multi-account วางแผนเที่ยวเชียงใหม่ 1 วัน ด้วย yolo1, cyolo1 และ gyolo1 งานทุกชิ้นใช้ความยาก 2
1. yolo1 เลือกสถานที่ 3 แห่งในตัวเมืองเชียงใหม่ พร้อมเหตุผลสั้น ๆ
2. ทำพร้อมกันหลังงานที่ 1: cyolo1 ทำตารางเวลา 09:00–18:00 สำหรับ 3 แห่งนั้น และ gyolo1 ประเมินค่าใช้จ่ายต่อคนเป็นบาท
3. yolo1 รวมตารางเวลาและค่าใช้จ่ายเป็นแผนเดียว
4. cyolo1 ตรวจแผนรวมว่าเวลาไม่ชนกันและยอดรวมค่าใช้จ่ายบวกถูก ตอบ ผ่าน หรือ ไม่ผ่าน
สรุปเป็นตาราง: งาน | บัญชี | ต้องรองานไหนก่อน | เวลา (วินาที) พร้อมแผนเที่ยวฉบับสุดท้าย แล้วเก็บแผนงานที่ใช้ไว้ที่ ./exercises/12
```

## คำตอบของ Claude

ทั้ง 5 งานรันสำเร็จ และ cyolo1 ตรวจแผนรวมแล้วตอบ **ผ่าน** (run `20261124-052446-qfkx`)

## ตารางสรุปงาน

| งาน | บัญชี (รุ่น) | ต้องรองานไหนก่อน | เวลา (วินาที) |
|---|---|---|---|
| 1. เลือกสถานที่ 3 แห่ง | yolo1 (sonnet/medium) | – | 5.7 |
| 2a. ตารางเวลา 09:00–18:00 | cyolo1 (gpt-6.2-sol/medium) | งาน 1 | 27.2 |
| 2b. ค่าใช้จ่ายต่อคน | gyolo1 (gemini-3.8-flash-medium) | งาน 1 | 30.4 |
| 3. รวมเป็นแผนเดียว | yolo1 (sonnet/medium) | งาน 2a, 2b | 16.5 |
| 4. ตรวจแผน | cyolo1 (gpt-6.2-sol/medium) | งาน 3 | 13.6 → **ผ่าน** |

งาน 2a กับ 2b รันพร้อมกัน ใช้เวลารวมจริงประมาณ 66 วินาที (5.7 + 30.4 + 16.5 + 13.6) ไม่มีการย้ายงานไปบัญชีอื่น

## แผนเที่ยวเชียงใหม่ 1 วัน (ฉบับสุดท้าย)

**สถานที่**
1. **วัดพระสิงห์วรมหาวิหาร**: วัดเก่าสไตล์ล้านนา มีพระพุทธสิหิงค์และจิตรกรรมฝาผนังที่สวยงาม
2. **วัดเจดีย์หลวงวรวิหาร**: เจดีย์โบราณขนาดใหญ่ที่เป็นสัญลักษณ์ของเมือง เดินจากวัดพระสิงห์ได้
3. **ถนนคนเดินท่าแพ (ประตูท่าแพ)**: ที่เดินเล่น ซื้อของ และชิมอาหารพื้นเมือง ใช้ปิดท้ายวัน

**ตารางเวลา**
| เวลา | กิจกรรม |
|---|---|
| 09:00–10:45 | วัดพระสิงห์ (พระพุทธสิหิงค์, วิหารลายคำ) |
| 10:45–11:00 | เดินไปวัดเจดีย์หลวง |
| 11:00–12:30 | วัดเจดีย์หลวง |
| 12:30–12:45 | เดินไปร้านอาหาร |
| 12:45–14:00 | กินข้าวกลางวัน (เช่น ข้าวซอย) |
| 14:00–15:30 | เดินถนนราชดำเนินไปประตูท่าแพ แวะดื่มกาแฟ |
| 15:30–17:00 | ชมประตูท่าแพและกำแพงเมืองเก่า |
| 17:00–18:00 | ถนนคนเดินท่าแพ |

> หมายเหตุ: ถนนคนเดินท่าแพเปิดเฉพาะวันอาทิตย์ จึงควรไปเที่ยววันอาทิตย์

**ค่าใช้จ่ายต่อคน**
| รายการ | บาท |
|---|---|
| ค่าเข้าชมวัดพระสิงห์ | 50 |
| ค่าเข้าชมวัดเจดีย์หลวง | 50 |
| ค่าเดินทาง (รถแดง/Grab) | 120 |
| อาหารกลางวัน | 80 |
| เครื่องดื่ม/ของว่าง | 70 |
| อาหารเย็น/ของกินที่ถนนคนเดิน | 150 |
| **รวม** | **520** |

ผมบวกยอดซ้ำเองแล้วได้ 520 ตรงกัน และช่วงเวลาต่อกันพอดีโดยไม่ทับกัน แต่ราคาทั้งหมดเป็นการประเมินของโมเดล ยังไม่ได้เทียบกับข้อมูลจริง ค่าเข้าวัดจริงอาจต่างจากนี้ เช่น คนไทยมักเข้าฟรี ส่วนชาวต่างชาติต้องเสียค่าเข้า
