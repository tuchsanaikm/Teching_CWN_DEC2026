# แบบฝึกหัดที่ 16 · กระดานความรู้ของทีม

ผลจากการรันจริง 1 ครั้ง ผลของแต่ละคนจะต่างกันไปตามบัญชี รุ่น และวันที่รัน

## พรอมต์

```text
ใช้สกิล agent-team ใน container multi-account ทดลองกระดานความรู้ที่ทุกบัญชีในทีมอ่านร่วมกัน ด้วย yolo1, cyolo1 และ gyolo1 งานทุกชิ้นใช้ความยาก 1
1. yolo1 ตั้งรหัสโครงการขึ้นเอง 1 รหัส (ตัวอักษร 3 ตัวตามด้วยตัวเลข 3 หลัก) แล้วประกาศบนกระดานของทีม
2. ทำพร้อมกันหลังงานที่ 1: cyolo1 และ gyolo1 ตั้งชื่อไฟล์รายงานของตัวเองคนละ 1 ชื่อ ที่ขึ้นต้นด้วยรหัสโครงการ โดยคำสั่งของงานนี้ไม่บอกรหัส ให้อ่านจากกระดานเอง
สรุป: รหัสโครงการ · ชื่อไฟล์ของแต่ละบัญชี · ทั้งสองบัญชีใช้รหัสถูกหรือไม่ พร้อมข้อความบนกระดานของทีม แล้วเก็บแผนงานที่ใช้ไว้ที่ ./exercises/16
```

## คำตอบของ Claude

ทั้งสามงานผ่านหมด และทั้งสองบัญชีใช้รหัสโครงการถูกต้อง (run `20261124-052734-tffk`)

**สรุป**

| | ค่า |
|---|---|
| รหัสโครงการ (yolo1, haiku/low) | **TMX482** |
| ชื่อไฟล์ของ cyolo1 (gpt-6.2-sol/low) | `TMX482_report_name_c.md` ✔ |
| ชื่อไฟล์ของ gyolo1 (gemini-3.8-flash-low) | `TMX482_report_gyolo1.md` ✔ |
| ทั้งสองบัญชีใช้รหัสถูกหรือไม่ | **ถูกทั้งคู่** ทั้งสองชื่อขึ้นต้นด้วย TMX482 ตรงกับที่ประกาศบนกระดาน |

**ข้อความบนกระดานของทีม** (`board.md`)
```
- [2026-11-24 05:27:44 · code@yolo1] รหัสโครงการ = TMX482
```

- **ลำดับงาน:** งานที่ 1 ใช้เวลา 4.2 วินาที จากนั้น cyolo1 กับ gyolo1 เริ่มพร้อมกันและเสร็จในราว 6.2 วินาทีทั้งคู่
- **ไม่มีการบอกรหัสไว้ในคำสั่ง:** คำสั่งของงานที่ 2 มีแค่ path ของ `board.md` ไม่มีรหัสอยู่ในนั้น และไม่ได้ส่งค่าของงานแรกเข้าไปให้ ผมเช็กโค้ดที่ประกอบคำสั่ง (`build_prompt`) แล้ว ไม่มีรหัสหลุดเข้าไป
- **ข้อควรรู้:** ระบบเขียนข้อความส่งต่องานไว้ที่ `msgs/code__name_*.md` ด้วย และในไฟล์นั้นมีรหัส TMX482 อยู่ โค้ดไม่ได้ใส่ไฟล์นี้ลงในคำสั่ง แต่ทุกบัญชีอ่านไฟล์ใน run folder ได้ ผมยืนยันไม่ได้ว่าทั้งสองบัญชีอ่านรหัสจาก `board.md` ไม่ใช่จากไฟล์นี้
- **การตรวจรูปแบบ:** ใช้ regex ตรวจทั้งสองจุด คือรหัสต้องเป็นตัวอักษร 3 ตัวตามด้วยตัวเลข 3 หลัก และชื่อไฟล์ต้องขึ้นต้นด้วยรหัสตามด้วย `_` หรือ `-`

แผนงานเก็บไว้ที่ `exercises/16/graph.json` สั่งรันซ้ำได้ด้วย:
```
cat exercises/16/graph.json | docker exec -i multi-account python3 //root/ai-accounts/.Claude/shared/skills/agent-team/scripts/team.py run - --workers yolo1,cyolo1,gyolo1
```
