# รายงานส่งมอบระบบ · ReceiptDesk (สำนักงานบัญชี ใส่ใจการบัญชี)

- **สถานะการส่งมอบ:** **ผ่านเกณฑ์ส่งมอบ (READY FOR DELIVERY)**
- **สถาปัตยกรรม:** เว็บ **Next.js 16 + Tailwind CSS v4 + PostgreSQL 16** บนเครื่องสำนักงาน เชื่อมต่อผ่าน HTTP/SSE ตรงไปยังคลัสเตอร์ AI **`1 โหนด × 2× RTX 4090`** ที่รัน **2× vLLM Replicas (`1 replica/GPU`, Data Parallelism 2×1, Continuous Batching `--max-num-seqs 256`)** หลัง **NGINX 1.27 (`least_conn`, `proxy_buffering off`, Bearer API Key, Passive Failover)**
