## สรุปผลการเช่าเครื่อง (ป้าย `vapp-lab6-nginx`)

เช่าเครื่องสำเร็จตั้งแต่ครั้งแรก และตรวจจากในเครื่องแล้วว่าเห็น GPU ครบ 2 ใบ

| รายการ | ค่า |
|---|---|
| GPU | RTX 3090 × 2 ใบ (ใบละ 24 GB) ในเครื่องเดียว |
| ราคาต่อชั่วโมง | $0.3578 (รวม disk 40 GB) |
| ที่ตั้ง | Quebec, แคนาดา |
| CPU ที่ใช้ได้จริง | ประมาณ 24.6 cores |
| เวลาที่รอจนเครื่องพร้อม | 56 วินาที (นับจากสั่งเช่าจน SSH เข้าได้) |

- **เครื่อง:** instance <id> เป็นข้อเสนอที่ถูกที่สุดตามเงื่อนไข ณ ตอนเช่า สถานะ verified และ reliability 0.9575
- **CPU:** ค่า 24.6 cores มาจากโควตา cgroup ของ container (2457600/100000) ส่วน `nproc` แสดง 64 threads ของทั้งเครื่อง และ Vast แจ้งไว้ที่ 25.6 cores
- **ระบบ:** PyTorch 2.8.0+cu128 (CUDA 12.8) จาก image `pytorch/pytorch:2.8.0-cuda12.8-cudnn9-runtime` และ `torch.cuda.device_count()` ได้ 2
- **พอร์ต 8080:** เรียกจากนอกเครื่องได้ที่ `http://203.0.113.10:‹port›` ทดสอบด้วยเว็บเซิร์ฟเวอร์ชั่วคราวแล้วได้คำตอบกลับ และปิดเซิร์ฟเวอร์ทดสอบแล้ว
- **SSH:** `root@203.0.113.10` พอร์ต ‹port› ใช้กุญแจ devtoolSSH

**เครื่องยังเปิดอยู่** (สถานะ running) และคิดเงินต่อเนื่องประมาณ $0.36 ต่อชั่วโมงจนกว่าจะสั่งลบ ยังไม่ได้ติดตั้ง API หรือ nginx บนเครื่อง
