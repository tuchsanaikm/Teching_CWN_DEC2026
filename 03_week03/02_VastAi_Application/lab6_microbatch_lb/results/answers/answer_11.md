## สรุปผล: GPU 1 ใบล่มกลางทาง (แบบที่ 4: GPU 2 ใบ · ใบละ 4 server · Round Robin)

ถ้า NGINX ไม่ป้องกัน ผู้ใช้เจอ error ครึ่งหนึ่งของคำขอหลัง GPU ล่ม แต่ถ้าป้องกัน ผู้ใช้ไม่เจอ error เลย

ยิง 60 ผู้ใช้ (หนึ่งในสามของความจุ 180 จากผล gpu2) นาน 60 วินาที โดย 5 วินาทีแรกเป็น warm-up วินาทีที่ 20.0 สั่ง `cluster.sh kill-gpu 1` ปิด server 4 ตัวของ GPU ใบที่ 2 (พอร์ต 8201–8204) ด้วย SIGKILL วัดรอบละ 1 ครั้ง

| | fail_off (ไม่ป้องกัน) | fail_on (ป้องกัน) |
|---|---|---|
| error จากคำขอทั้งหมด (รวม warm-up) | 11,206 / 32,769 = 34.2 % (HTTP 502 ทั้งหมด) | 0 / 20,413 = 0 % |
| error ของคำขอที่ค้างอยู่ตอนล่ม (60 คำขอ) | 21 | 0 |
| error ของคำขอที่เริ่มหลังล่ม | 11,087 / 22,175 = 50.0 % | 0 / 10,218 |
| Throughput ที่สำเร็จ ก่อนล่ม (วินาที 5–20) | 522.1 req/s | 506.3 req/s |
| Throughput ที่สำเร็จ หลังล่ม (ถึงวินาที 60) | 279.6 req/s | 257.4 req/s |
| p95 หลังล่ม (เฉพาะคำขอที่สำเร็จ) | 197.4 ms | 346.3 ms |
| หลังล่ม p95 ไม่เกิน 500 ms ไหม | ผ่าน แต่ error 50 % จึงใช้งานไม่ได้ | ผ่าน และ error 0 % |

- **fail_off:** NGINX ยังส่งคำขอทุก ๆ คำขอที่สองไปยัง server ที่ล่ม ผู้ใช้จึงได้ 502 ทันที p95 ต่ำกว่ารอบ fail_on เพราะคำขอครึ่งหนึ่งล้มเร็ว server ที่เหลือจึงรับงานน้อยลง
- **fail_on:** GPU ใบแรกรับผู้ใช้ทั้ง 60 คนเพียงใบเดียว p95 ทั้งช่วงหลังล่มผ่านเกณฑ์ แต่มี 2 วินาที (วินาทีที่ 33 และ 37) ที่ p95 รายวินาทีเกิน 500 ms (506.7 และ 532.9 ms) ยังไม่ได้หาสาเหตุ

### การตั้งค่า NGINX ที่ใช้ป้องกัน (`cluster.sh up --failover on`)

- `proxy_next_upstream error timeout non_idempotent;` คำขอที่ล้มเพราะต่อ server ไม่ได้ ถูกตัดการเชื่อมต่อ หรือหมดเวลา จะถูกส่งต่อให้ server ตัวถัดไป ต้องมี `non_idempotent` เพราะ `/v1/detect` เป็น POST ซึ่ง NGINX ปกติจะไม่ส่งซ้ำเมื่อส่งออกไปแล้ว
- `server 127.0.0.1:PORT max_fails=1 fail_timeout=10s;` server ที่ล้ม 1 ครั้งจะถูกพักไม่รับงาน 10 วินาที จากนั้น NGINX ลองส่งคำขอทดสอบ 1 คำขอ ถ้ายังล้มก็ส่งต่อให้ตัวอื่นและพักอีก 10 วินาที
- รอบไม่ป้องกันใช้ `proxy_next_upstream off;` กับ `max_fails=0` คือไม่ส่งต่อ และไม่ตัด server ที่ล่มออกจากวงรอบ

ถ้าไม่ใส่ `--failover` ระบบใช้ค่าเดิมของการวัดความจุทุกครั้งที่ผ่านมา
