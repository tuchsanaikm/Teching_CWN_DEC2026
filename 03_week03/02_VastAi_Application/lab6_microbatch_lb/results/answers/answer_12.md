# สรุปงาน LAB 6: กราฟ เก็บผล และลบเครื่อง

งานครบทั้ง 4 ขั้น: เขียน `code/report.py` รวมตัวเลขและวาดกราฟ 7 รูป นำผลและโค้ดกลับมาครบ และลบเครื่องป้าย `vapp-lab6-nginx` แล้ว ยอดเงินใน billing ยังขึ้นไม่ครบตามอายุเครื่อง (ดูหัวข้อค่าใช้จ่าย)

## ตาราง 4 แบบ

เกณฑ์ผ่านคือ p95 ≤ 500 ms และ error < 1 % ความจุคือจำนวนผู้ใช้พร้อมกัน (N) สูงสุดที่ผ่านเกณฑ์

| # | จำนวน GPU | แบบ | ความจุ (N) | Throughput สูงสุด | p95 ที่ความจุ | เท่าของแบบที่ 1 |
|---|---|---|---|---|---|---|
| 1 | 1 | base: 1 server, 1 รูปต่อครั้ง | 29 | 62.6 req/s (N=29) | 494.4 ms | 1.00 |
| 2 | 1 | batch: 1 server, micro-batching | 52 | 142.9 req/s (N=64) | 490.0 ms | 1.79 |
| 3 | 1 | multi: 4 server บน GPU เดียว, micro-batching | 90 | 278.7 req/s (N=128) | 468.4 ms | 3.10 |
| 4 | 2 | gpu2: 2 GPU × 4 server, micro-batching | 180 | 566.5 req/s (N=512) | 490.3 ms | 6.21 |

- **Round Robin เทียบ Least Connections (GPU เท่ากัน):** ความจุ 180 เทียบ 250 สัดส่วนคำขอเป็น 50/50 ทั้งคู่
- **เมื่อ GPU 1 ช้าลง 3 เท่า:** ความจุ 52 เทียบ 103 โดย Round Robin ยังแบ่ง 50/50 ส่วน Least Connections แบ่ง 70.8 % / 29.2 %
- **GPU ล่มที่วินาที 20 (60 ผู้ใช้):**
  - failover off: error 11,206 จาก 32,769 คำขอ (34.2 %, HTTP 502 ทั้งหมด)
  - failover on: error 0 จาก 20,413 คำขอ หลังล่มได้ 257 req/s และ p95 346 ms

## กราฟและไฟล์

- **ตัวเลขรวม:** `results/metrics.json` รวมผลทั้ง 9 ชุด (base, batch, multi, gpu2, lc_equal, rr_slow, lc_slow, fail_off, fail_on)
- **กราฟ:** 7 รูปใน `results/images` ข้อความอังกฤษ เปิดดูแล้วอ่านออกทุกรูป หลังแก้ป้ายและ legend ที่ทับกันในรูป 1 และ 7 (รูป 4 มีป้ายค่า 32.0 สองจุดทับเส้นประ max batch แต่ยังอ่านได้)
  1. `1_p95_vs_users.png` — p95 เทียบ N พร้อมเส้น 500 ms และจุดความจุ
  2. `2_throughput_vs_users.png` — Throughput เทียบ N
  3. `3_capacity_bar.png` — แท่งความจุ
  4. `4_images_per_call_vs_users.png` — จำนวนรูปเฉลี่ยต่อการเรียกโมเดล เทียบ N
  5. `5_gpu_cpu_at_capacity.png` — GPU % และ CPU ของ server ที่ความจุ
  6. `6_round_robin_vs_least_conn.png` — ความจุและสัดส่วนคำขอ ทั้ง 2 กรณี
  7. `7_gpu_failure.png` — คำขอต่อวินาทีแยกสี GPU 0 / GPU 1 / error ทั้ง 2 รอบ

- **การนำผลกลับ:** ไฟล์บนเครื่องเช่า 129 ไฟล์ (`results`, `code`, `code_before_lb`, `logs`, `requirements.lock`) มาครบ md5 ตรงทุกไฟล์ โฟลเดอร์รวมประมาณ 116 MB ส่วนใหญ่คือ `logs/nginx/access.log` 100 MB
