## สรุปงาน: เช่า 3 Node และเตรียมโมเดลกับ Dataset

เช่าเครื่องครบ 3 เครื่อง โหลดโมเดลและ Dataset ครบทุก Node แบ่งชุดข้อมูลได้ชุดเดียวกัน และ Node 2 กับ Node 3 ต่อเข้า port ของ Node 1 ได้ **ทั้ง 3 เครื่องยังเปิดอยู่และคิดเงินต่อเนื่อง รวม $1.3484 ต่อชั่วโมง**

### เครื่องที่ได้

| Node | ป้าย | Instance ID | ที่ตั้ง | IP สาธารณะ | GPU | CPU cores (เครื่อง / ได้ใช้จริง) | ราคาต่อชั่วโมง |
|---|---|---|---|---|---|---|---|
| Node 1 | vapp-lab5-3dp-1 | <id> | เอสโตเนีย | 203.0.113.10 | RTX 3090 × 2 | 72 / 36 | $0.4140 |
| Node 2 | vapp-lab5-3dp-2 | <id> | บัลแกเรีย | 203.0.113.10 | RTX 3090 × 2 | 128 / 13.5 | $0.4164 |
| Node 3 | vapp-lab5-3dp-3 | <id> | โรมาเนีย | 203.0.113.10 | RTX 3090 × 2 | 32 / 12.8 | $0.5180 |

- **ระบบ:** ทุกเครื่องเป็น PyTorch 2.8.0 กับ CUDA 12.8 disk 60 GB และพร้อมใช้ภายในประมาณ 5 นาที จึงไม่ต้องลบแล้วเช่าใหม่
- **port ของ Node 1:** port 9000 ในเครื่อง ต่อจากภายนอกที่ 203.0.113.10:<ext_port>
- **การเลือกเครื่อง:** เครื่องที่ถูกที่สุด 3 อันดับแรกอยู่คนละทวีป (สหรัฐฯ $0.38 เอสโตเนีย บัลแกเรีย) จึงเลือกชุดที่ถูกที่สุดในยุโรปแทนเพื่อให้อยู่ใกล้กัน
- **ข้อควรรู้เรื่อง CPU:** เงื่อนไข 16 cores ผ่านเมื่อนับ cores ของทั้งเครื่อง แต่ส่วนที่ instance ได้ใช้จริงของ Node 2 และ Node 3 ต่ำกว่า 16 (13.5 และ 12.8) ถ้าต้องการให้ส่วนที่ได้ใช้จริงถึง 16 ในยุโรปมีเพียง 2 เครื่องที่ผ่าน (เอสโตเนีย และเช็ก $0.5344) จึงหา 3 เครื่องใกล้กันไม่ได้

### เน็ตระหว่าง Node (ต่อเข้า port ของ Node 1)

| เส้นทาง | ต่อเข้าได้ | RTT เฉลี่ย (ต่ำสุด–สูงสุด) | ส่งไป Node 1 | รับจาก Node 1 |
|---|---|---|---|---|
| Node 2 → Node 1 | ได้ | 73.58 ms (73.39–73.78) | 281.6 Mbps | 185.8 Mbps |
| Node 3 → Node 1 | ได้ | 81.15 ms (79.53–82.43) | 233.9 Mbps | 73.2 Mbps |

วัดด้วย TCP เส้นเดียว ทิศละ 10 วินาที รอบเดียว และ RTT จาก 50 ครั้ง ตัวเลขความเร็วจึงอาจแกว่งได้ถ้าวัดซ้ำ ทิศ Node 1 → Node 3 ช้ากว่าทิศอื่นชัดเจน

### อธิบายตัวอย่าง 1 รายการ

ตัวอย่างที่ 3 จากตาราง 6 รายการใน `results/dataset_samples.md`:

- **คำถาม (question):** `Which engine has a year larger than 1956?` คือคำถามภาษาอังกฤษที่ผู้ใช้ถาม เป็น input ของโมเดล
- **โครงสร้างตาราง (context):** `CREATE TABLE table_name_74 (engine VARCHAR, year INTEGER)` คือคำสั่งสร้างตารางที่บอกชื่อตาราง ชื่อคอลัมน์ และชนิดข้อมูล โมเดลใช้ส่วนนี้เพื่อรู้ว่ามีคอลัมน์อะไรให้อ้างถึง
- **SQL เฉลย (answer):** `SELECT engine FROM table_name_74 WHERE year > 1956` คือคำสั่ง SQL ที่ถูกต้อง เป็นคำตอบที่โมเดลต้องเรียนรู้ให้สร้างได้
