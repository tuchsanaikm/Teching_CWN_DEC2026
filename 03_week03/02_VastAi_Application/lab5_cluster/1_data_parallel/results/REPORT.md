## หมายเหตุ

- ลอง 3 step (batch = ตัวอย่างยาวที่สุด 1 + สั้นที่สุด 3, pad ถึง 256 token): แบบ `model(labels=...)` ที่คำนวณ logits ทุกตำแหน่ง **Out of Memory** บน GPU ที่ได้ batch กว้าง 256 (`results/trial_full`) → แก้ `worker.py` ให้คำนวณ logits เฉพาะตำแหน่งที่มี label (คำตอบ SQL) ค่า loss เท่าเดิม → ผ่าน VRAM สูงสุด 22,063 MiB (`results/trial`) ค่าที่ตรึงไม่เปลี่ยน
- เวลาต่อ step เฉลี่ย 3.56 s รวมช่วงที่เน็ตขาขึ้น Node 2 → Node 1 สะดุด 2 ช่วง (16 step ใช้ 6–44 s รวม 462 s) · median 2.67 s · ถ้าไม่นับ 16 step นั้นเฉลี่ย 2.72 s · ไม่มี reconnect ตลอดการเทรน
- ทดสอบการเชื่อมต่อหลุด (`results/trial_reconnect`): ปิดโปรแกรมกลางกลางทางแล้วเปิดใหม่ โปรแกรมเทรนทั้ง 4 ต่อกลับเอง ส่ง Gradient ของ step เดิมซ้ำ รันครบ 12 step น้ำหนักเท่ากัน
- ที่เลือกเอง (โจทย์ไม่ได้ตรึง): AdamW weight decay 0 · learning rate คงที่ · LoRA dropout 0 · น้ำหนัก LoRA เป็น float32 (โมเดลฐาน bf16, autocast bf16) · Gradient ส่งเป็น float32 ไม่บีบอัด
- Exact Match เข้มงวด: ตัดช่องว่างซ้ำและ `;` ท้ายคำสั่งเท่านั้น ตัวพิมพ์ใหญ่เล็กและชนิดเครื่องหมายคำพูดนับเป็นผิด (Base ตอบด้วย `'...'` และตัวพิมพ์ต่างจากเฉลยเป็นส่วนใหญ่ จึงได้ 1.5%)
- Base วัดบน Node 1 GPU 0 · Epoch 1 ใช้ adapter ของ rank 1 (Node 1) · Epoch 2 ใช้ adapter ของ rank 2 (Node 2)
