สรุปผลเสร็จครบ: ดึงผลดิบของทั้ง 2 Node กลับมาแล้ว, `code/report.py` สร้าง `results/metrics.json` กับกราฟ 4 รูป, และลบเครื่อง `vapp-lab5-dp-1` กับ `vapp-lab5-dp-2` แล้ว ตรวจซ้ำไม่เหลือในบัญชี

## ผลการเทรน (2 Node · 4 × RTX 3090 · batch รวม 16 · 500 step · 2 Epoch)

| รายการ | ค่า |
|---|---|
| ตัวอย่างต่อวินาที | **4.50** (8,000 ตัวอย่างใน 1,777.5 วินาที) |
| เวลาต่อ step | เฉลี่ย 3.56 วินาที (median 2.67) |
| สัดส่วนเวลาที่ใช้ส่งและรอ | **87.8%** (3.11 วินาที เทียบกับคำนวณ 0.43 วินาที) |
| GPU util เฉลี่ย | 12.7% (แต่ละใบ 12.4 / 12.8 / 12.7 / 12.8%) |
| Exact Match บน Test Set 200 ตัวอย่าง | โมเดลตั้งต้น 1.5% → Epoch 1 **72.5%** (145/200) → Epoch 2 **75.0%** (150/200) |
| loss บน Test Set | 1.858 → 0.060 → 0.051 |
| เงินต่อ 1,000 ตัวอย่าง | **$0.0605** (ราคา 2 เครื่องรวม $0.9802/ชม.) |

- **คอขวดคือการส่งและรอ:** GPU ทำงานจริงเพียงราว 12% ของเวลา ที่เหลือรอส่ง Gradient และรอค่าเฉลี่ยกลับมา
- **Epoch 1 ช้ากว่า Epoch 2:** ได้ 3.63 ตัวอย่าง/วินาที เทียบกับ 5.92 เพราะช่วง step 120–200 มี step ที่ช้าผิดปกติ (สูงสุดราว 19 วินาทีต่อ step) GPU util ตกเกือบ 0 ในช่วงเดียวกัน
- **เงินต่อ 1,000 ตัวอย่าง** คิดจากราคาต่อชั่วโมงของ 2 เครื่องกับความเร็วเฉลี่ยตลอดการเทรน ไม่รวมเวลาเตรียมเครื่อง การวัดผล และค่า bandwidth
