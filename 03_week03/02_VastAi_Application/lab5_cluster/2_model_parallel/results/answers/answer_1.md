## อธิบายตัวอย่าง 1 รายการ

ตัวอย่างที่ 1 ใน `results/dataset_samples.md`:

- **คำถาม (question):** `What is the lowest unlock order for the athens circuit?` คือคำถามภาษาอังกฤษที่ผู้ใช้ถาม เป็นข้อมูลเข้าของโมเดล
- **โครงสร้างตาราง (context):** `CREATE TABLE table_24463470_1 (unlock_order INTEGER, circuit VARCHAR)` คือคำสั่งสร้างตารางที่บอกชื่อตาราง ชื่อคอลัมน์ และชนิดข้อมูล โมเดลใช้ส่วนนี้เพื่อรู้ว่ามีคอลัมน์อะไรให้อ้างถึง
- **SQL เฉลย (answer):** `SELECT MIN(unlock_order) FROM table_24463470_1 WHERE circuit = "Athens"` คือคำตอบที่ถูกต้อง ใช้เป็นเป้าหมายตอนฝึกและเป็นเฉลยตอนวัดผล ในข้อนี้ "lowest" กลายเป็น `MIN(...)` และ "athens circuit" กลายเป็นเงื่อนไข `WHERE`

## เรื่อง key

รายงานนี้ไม่มีค่า key แต่ตอนสั่งสร้างเครื่อง คำสั่ง `vastai create instance --raw` พิมพ์ค่า `instance_api_key` ของทั้งสองเครื่องออกมาในผลลัพธ์ของคำสั่งระหว่างทำงาน ค่านี้เป็น key เฉพาะเครื่อง ไม่ใช่ key ของบัญชี และไม่ได้ถูกบันทึกลงไฟล์ใด ถ้าต้องการให้ key สองตัวนี้ใช้ไม่ได้ ต้องลบเครื่องทั้งสอง
