## ผลสรุป

| รายการ | รวม 2 Epoch | Epoch 1 | Epoch 2 |
|---|---|---|---|
| ตัวอย่างต่อวินาที | **4.90** | 4.27 | 5.76 |
| เวลาต่อ step | 3.27 วินาที (คำนวณ 0.70 + ส่งและรอ 2.56) | 3.75 วินาที | 2.78 วินาที |
| สัดส่วนเวลาที่ใช้ส่งและรอ | **78.5%** | 81.2% | 74.9% |
| Exact Match (200 ข้อ) | Base 1.5% (3/200) | **69.5%** (139/200) | **74.0%** (148/200) |
| เงินต่อ 1,000 ตัวอย่าง | **$0.0513** | $0.0590 | $0.0437 |

- **เงินต่อ 1,000 ตัวอย่าง** คิดจากราคา 2 เครื่องรวมกัน $0.9058 ต่อชั่วโมง ($0.3956 + $0.5102 รวม GPU และดิสก์) หารด้วย 4.90 ตัวอย่างต่อวินาที ไม่รวมค่าอินเทอร์เน็ตและเวลาเตรียมเครื่อง
- **เวลาต่อ step** รวม step ที่ค้าง 67 วินาทีตอนต่อใหม่หลัง host ของ Node 1 ดับไว้ด้วย ส่วนช่วงที่เครื่องดับเองไม่นับ
- **GPU util** เฉลี่ยระหว่างเทรนต่ำทุกใบ: Node 1 ได้ 10.6% / 10.8% และ Node 2 ได้ 10.8% / 9.4% (GPU 0 / GPU 1)
- **Loss** เฉลี่ยต่อ Epoch ลดจาก 0.121 เป็น 0.038 (step แรก 1.66) ส่วน test loss เป็น 0.060 และ 0.054

## การลบเครื่อง

- ลบเฉพาะ instance <id> และ <id> โดยตรวจป้ายให้ตรงก่อนลบ
- เครื่องป้ายอื่นที่เหลือในบัญชีไม่ได้แตะ
- ไฟล์ `ckpt_*.pt` (checkpoint ระหว่างเทรน ไฟล์ละ 46 MB) ไม่ได้ดึงกลับมาและหายไปพร้อมเครื่อง ส่วนน้ำหนัก LoRA ของทั้ง 2 Epoch ทั้ง 2 Node เก็บไว้แล้วใน `results/run`
