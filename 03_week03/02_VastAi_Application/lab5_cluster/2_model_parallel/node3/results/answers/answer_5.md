# สรุปผล: เทรน Qwen3-8B แบบ Model Parallelism บน 3 Node

เทรนครบ 2 Epoch (334 step) ไม่ Out of Memory การเชื่อมต่อไม่หลุด และน้ำหนัก LoRA ของทั้ง 3 Node เท่ากันหลังจบทุก Epoch — Exact Match ขึ้นจาก 1.5% (Base) เป็น 71.0%

**เครื่องทั้ง 3 Node ยังเปิดอยู่** (สถานะ running รวมประมาณ $1.33/ชม.): vapp-lab5-3mp-1, vapp-lab5-3mp-2, vapp-lab5-3mp-3

- **Exact Match:** ตัดช่องว่างหัวท้าย รวมช่องว่างซ้ำ และตัด `;` ท้ายคำสั่ง นอกนั้นต้องตรงทุกตัวอักษร Base ผิดเกือบทั้งหมดเพราะใช้ `'` แทน `"` และใช้ตัวพิมพ์ใหญ่ต่างจากเฉลย
- **การตรวจน้ำหนัก:** ตรวจสองทาง คือ worker ส่ง sha256 ให้โปรแกรมกลางเทียบตอนจบ Epoch และคำนวณ sha256 ซ้ำจากไฟล์ที่บันทึกไว้บนแต่ละ Node ได้ค่าตรงกัน

## ทดสอบ 3 step ก่อนเทรน
- ใช้ batch ที่มี 4 ตัวอย่างยาวที่สุดกับ 4 ตัวอย่างสั้นที่สุดของแต่ละ Node (Node 1 มีตัวอย่าง 256 token จึง pad ถึง 256)
- ผ่านทั้ง 3 Node โดยไม่ต้องแก้โค้ดเรื่องหน่วยความจำ ใช้ VRAM สูงสุดประมาณ 14 GB จาก 24 GB
- รอบแรกช้ามาก (20–70 วินาทีต่อ step) เพราะผมตั้งขนาด socket buffer เอง ทำให้ TCP window ค้างที่ 64 KB แก้โดยเลิกตั้งค่านี้ แล้วเหลือประมาณ 3.5 วินาทีต่อ step

## สิ่งที่ผมเลือกเองนอกเหนือจากค่าที่ตรึง
- **LoRA เขียนเอง:** เก็บน้ำหนัก LoRA เป็น float32 แต่คำนวณ forward เป็น bf16 ตามโมเดล เพื่อไม่ให้การปรับน้ำหนักขนาดเล็กถูกปัดทิ้ง
- **Optimizer:** AdamW แบบ lr คงที่ 2e-4 ไม่มี weight decay และไม่มี warmup ผมไม่ได้เปิดดูโค้ดของ LAB 4.3 ถ้า LAB 4.3 ตั้งต่างจากนี้ ตัวเลข loss และ Exact Match จะเทียบกันตรง ๆ ไม่ได้
- **รูปแบบ prompt:** system prompt สั้น ๆ ตามด้วย Schema และ Question คิด loss เฉพาะ token ของคำตอบ SQL
- **step สุดท้ายของ Epoch:** มี 6+5+5 ตัวอย่าง (ไม่ครบ 24) โปรแกรมกลางจึงเฉลี่ยแบบถ่วงน้ำหนักตามจำนวนตัวอย่าง
- **การประเมิน:** รันหลังเทรนจบพร้อมกัน 3 Node — Base บน Node 1, Epoch 1 จากไฟล์ของ Node 2, Epoch 2 จากไฟล์ของ Node 3

## การรันต่อเมื่อการเชื่อมต่อหลุด
- โปรแกรมกลางและ worker รันแบบ detached บน Node จึงไม่หยุดเมื่อ SSH หลุด
- worker ต่อใหม่และส่ง Gradient ของ step เดิมซ้ำได้เมื่อการเชื่อมต่อกับโปรแกรมกลางหลุด แต่ส่วนนี้ยังไม่ได้ถูกทดสอบจริง เพราะรอบนี้ไม่มีการหลุดเลย
- ถ้า worker หรือโปรแกรมกลางล่มกลางทาง ยังไม่มีการเทรนต่อจากจุดเดิม (บันทึก LoRA เฉพาะตอนจบ Epoch)
