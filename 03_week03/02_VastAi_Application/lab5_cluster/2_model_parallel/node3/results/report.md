## ทดสอบ 3 step ก่อนเทรน
batch = 4 ตัวอย่างยาวที่สุด + 4 ตัวอย่างสั้นที่สุดของแต่ละ Node (Node 1: [187, 189, 206, 256, 64, 65, 66, 66] token, pad ถึง 256) · ผ่านทั้ง 3 Node ไม่ Out of Memory · VRAM สูงสุด 13.58 / 14.03 GB จาก 24 GB
รอบแรกช้ามาก (20–70 วินาที/step) เพราะตั้ง SO_RCVBUF เองทำให้ TCP window ค้างที่ 64 KB แก้โดยเลิกตั้งค่า buffer (logs ใน run/smoke_try1_slow_window บน Node)
