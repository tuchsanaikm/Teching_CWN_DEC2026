1Data Parallelism (2_data_parallel/) ให้ GPU ทุกใบในเครื่องถือโมเดลครบชุด แล้วแบ่งข้อมูลกันเทรน เหมาะเมื่ออยากให้ เสร็จเร็วขึ้น
2Model Parallelism (3_model_parallel/) แบ่ง Layer ของโมเดลชุดเดียวลงหลายใบในเครื่องเดียวกัน เหมาะเมื่อ VRAM ไม่พอ สำหรับโมเดลหรือ batch ที่ต้องการ
3Single GPU (1_single_gpu/) เป็นจุดตั้งต้น (1 เครื่อง × 1 ใบ) ไว้เทียบว่าเมื่อเพิ่มเป็น 2 ใบและ 4 ใบในเครื่องเดียว แต่ละแบบให้อะไรกลับมาจริง

พื้นฐานร่วม · โมเดลและ LoRA

กลไก Attention ในแต่ละ Layer แปลงทุกคำเป็น Query, Key และ Value

1Query (q_proj) คือคำค้นที่ถือไว้ว่ากำลังต้องการข้อมูลอะไร
2Key (k_proj) คือป้ายกำกับที่บอกว่าคำนี้เกี่ยวกับอะไร ใช้เทียบกับ Query
3Value (v_proj) คือเนื้อหาที่จะหยิบไปใช้ต่อเมื่อเลือกได้แล้ว
พื้นฐานร่วม · โมเดลและ LoRA

3เพราะข้อมูลที่ส่งมีแค่ ~15 MB แม้เครื่อง 2 ใบไม่มี NVLink (ผ่าน PCIe ข้าม NUMA) ช่วงรอกันก็ยังสั้นมาก
