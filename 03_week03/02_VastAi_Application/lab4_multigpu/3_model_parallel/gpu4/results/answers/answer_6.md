| รายการ | ค่า |
|---|---|
| batch ใหญ่สุด | **16** (batch 32 เกิด Out of Memory ที่ GPU 3) |

- **ราคาตลาด:** เครื่อง RTX 3090 4 ใบแบบ on-demand ที่ถูกที่สุดคือ $0.5394/ชม. (verified, California) จากข้อเสนอทั้งหมด 34 รายการ
- **ข้อสังเกตเรื่องราคา:** ข้อเสนอนี้ไม่ขึ้นในการค้นแบบตัวกรองเริ่มต้นของ CLI ซึ่งถูกสุดอยู่ที่ $0.646/ชม. ถ้าใช้ราคานั้น เงินต่อ 1,000 ตัวอย่างจะราว $0.018
- **VRAM ที่ batch 16:** GPU 0 = 11.4 GB, GPU 1 = 9.3 GB, GPU 2 = 9.3 GB, GPU 3 = 18.4 GB โดย GPU 3 หนักสุดเพราะถือ LM Head
- **GPU util เฉลี่ย:** 24.9% / 21.8% / 23.1% / 30.3% (เฉลี่ย 4 ใบ 25.0%) เพราะแต่ละใบผลัดกันทำงาน
- **loss:** train loss เฉลี่ยราย Epoch 0.1233 → 0.0382 → 0.0252 ส่วน test loss 0.0629 → 0.0536 → 0.0540
