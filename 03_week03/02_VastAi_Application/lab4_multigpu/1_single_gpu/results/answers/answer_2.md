## สิ่งที่เกิดระหว่างทาง
- **รอบแรกล้มด้วย Out of Memory ที่ step ประมาณ 740 ของ Epoch 1** ทั้งที่ batch 4 ผ่านการลองแล้ว ผมแก้โดยไม่ส่ง attention mask ตอนเทรน แล้วรันใหม่ทั้งหมดตั้งแต่การลอง batch ผลในตารางมาจากรอบที่สองล้วน ๆ และรอบนี้ผ่านจุดเดิมได้
- **สาเหตุที่ผมสันนิษฐาน:** batch จริงมี padding ทำให้ attention ใช้หน่วยความจำมากกว่า batch ตอนลองที่ไม่มี padding ผมไม่ได้ทดสอบแยกเพื่อยืนยันกลไกนี้ การตัด mask ออกไม่เปลี่ยนค่า loss เพราะ padding อยู่ด้านขวาและไม่ถูกคิด loss
- **การรันต่อหลังหลุด:** งานรันใน tmux และทุกขั้นข้ามเองถ้ามีผลแล้ว ผมทดสอบในรอบแรกโดยฆ่างานที่ step 120 แล้วสั่งใหม่ มันเทรนต่อจาก checkpoint ที่ step 100 ได้จริง
- **ค่าที่ผมเลือกเองเพราะโจทย์ไม่ได้ตรึง:** AdamW, learning rate คงที่ไม่มี warmup, LoRA dropout 0, สร้างคำตอบแบบ greedy ไม่เกิน 128 token
- **ตัวอย่างที่ถูกตัดที่ 256 token:** มี 1 ตัวอย่างใน Training Set ส่วน Test Set ไม่มี
