## สรุปผล

เช่าเครื่อง RTX 3090 1 ใบได้แล้ว โหลดโมเดลกับ Dataset ลงเครื่องครบ และแบ่งชุดข้อมูลเสร็จ **เครื่องยังเปิดอยู่และคิดเงินต่อเนื่อง** ($0.1944 ต่อชั่วโมง)

| รายการ | ค่า |
|---|---|
| เครื่องที่ได้ | instance `<id>` (machine 27359) · RTX 3090 24 GB × 1 · Ontario, แคนาดา · ป้าย `vapp-lab4-single` |
| ราคาต่อชั่วโมง | $0.1944 (รวม disk 60 GB) |
| ระบบ | PyTorch 2.8.0+cu128 · CUDA 12.8 · disk 60 GB (ใช้ไป 16 GB) |
| โมเดล | Qwen/Qwen3-8B ขนาด 16.4 GB อยู่ที่ `/workspace/lab4/models/Qwen3-8B` บนเครื่องเช่า |
| Dataset | b-mc2/sql-create-context ทั้งหมด 78,577 ตัวอย่าง สับด้วย seed 0 |
| Training Set | 4,000 ตัวอย่าง |
| Test Set | 200 ตัวอย่าง (ไม่ซ้ำกับ Training Set) |

เครื่องพร้อมใช้ภายในไม่ถึง 1 นาที จึงไม่ต้องเปลี่ยนเครื่องเพราะรอนาน

### สิ่งที่ควรรู้
- **เช่าสองครั้ง:** ครั้งแรกได้เครื่อง $0.2067 (instance `<id>`) แต่มีข้อเสนอ $0.1944 โผล่มาพร้อมกัน จึงลบเครื่องแรกทันทีแล้วเช่าเครื่องที่ถูกกว่า เครื่องแรกเปิดอยู่ไม่กี่วินาที
- **เงื่อนไข CUDA:** ข้อเสนอที่ถูกกว่านี้ ($0.19 และ $0.2033) รองรับ CUDA ได้แค่ 12.4 และ 12.2 จึงข้ามไป เพราะใช้ image CUDA 12.8 ไม่ได้
- **กุญแจ SSH:** กุญแจ `devtoolSSH` ยังไม่ได้ลงทะเบียนในบัญชี จึงผูกกับเครื่องนี้เครื่องเดียว ไม่ได้เพิ่มเข้าบัญชี

### อธิบายตัวอย่าง 1 รายการ (รายการที่ 1 ของ Training Set)

| ช่อง | ค่า | ความหมาย |
|---|---|---|
| คำถาม (`question`) | What is the lowest unlock order for the athens circuit? | คำถามภาษาธรรมชาติที่ผู้ใช้ถาม เป็น input ของโมเดล |
| โครงสร้างตาราง (`context`) | `CREATE TABLE table_24463470_1 (unlock_order INTEGER, circuit VARCHAR)` | คำสั่ง `CREATE TABLE` ที่บอกชื่อตาราง ชื่อคอลัมน์ และชนิดข้อมูล ให้โมเดลรู้ว่าต้องเขียน SQL กับตารางแบบไหน |
| SQL เฉลย (`answer`) | `SELECT MIN(unlock_order) FROM table_24463470_1 WHERE circuit = "Athens"` | คำสั่ง SQL ที่ถูกต้อง เป็นคำตอบที่โมเดลต้องเรียนรู้ให้สร้างได้ ในที่นี้ "lowest" กลายเป็น `MIN(...)` และ "athens circuit" กลายเป็นเงื่อนไข `WHERE` |
