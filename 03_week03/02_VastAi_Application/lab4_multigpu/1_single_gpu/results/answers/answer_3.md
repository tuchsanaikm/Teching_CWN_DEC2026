## สรุปผล Lab 4 / 1_single_gpu (Qwen3-8B + LoRA บน RTX 3090 1 ใบ)

ทำครบทั้ง 5 ขั้น: ผลดิบอยู่ที่ `results/raw`, ได้ `results/metrics.json` กับกราฟ 3 รูป และลบเครื่อง `vapp-lab4-single` แล้ว

| รายการ | ค่า |
|---|---|
| batch ใหญ่สุด | **4** (VRAM สูงสุด 22.98 GB จาก 24 GB · batch 8 Out of Memory) |
| ตัวอย่างต่อวินาที | **8.49** (12,000 ตัวอย่างใน 1,413.6 วินาที นับเฉพาะช่วงเทรน) |
| Exact Match | **77.5%** หลัง Epoch 3 (155/200) |
| เงินต่อ 1,000 ตัวอย่าง | **$0.00456** ที่ราคาตลาดถูกสุด $0.1394/ชม. |

- **Exact Match รายจุด:** Base 1.5% → Epoch 1 77.0% → Epoch 2 79.0% (สูงสุด) → Epoch 3 77.5%
- **loss:** train loss ลดจาก 0.0713 เหลือ 0.0198 และ test loss จาก 0.0529 เหลือ 0.0489 ตลอด 3 Epoch
- **VRAM เทียบ batch:** batch 1 ใช้ 17.24 GB, batch 2 ใช้ 19.15 GB, batch 4 ใช้ 22.98 GB
